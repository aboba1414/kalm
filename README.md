# Kalm

**Kalm** — нативное приложение в стиле **Qt 6 + KDE Kirigami (`FormCard`)** для управления активным шумоподавлением (ANC), звуковыми профилями и параметрами наушников **vivo TWS 5 / 5 Hi-Fi** (и других моделей линейки vivo / iQOO TWS) в Linux.

## Возможности
- **Интерфейс KDE Kirigami + FormCard**: автоматически подстраивается под системную цветовую схему KDE Plasma 6 (Breeze, Gruvbox и др.), шрифты и иконки.
- **Режимы шумоподавления**:
  - `Шумоподавление (ANC)`
  - `Выключено`
  - `Прозрачность`
- **Несколько пар наушников**:
  - Добавление любых сопряжённых наушников через встроенный сканер Bluetooth или по MAC-адресу
  - Переименование (свои ярлыки), удаление и быстрое переключение между парами в окне, системном трее или CLI
  - Опция **автопереключения** на ту пару из списка, которая сейчас подключена по Bluetooth
- **Интеграция с системным треем KDE Plasma**:
  - Иконка с индикатором активного режима (`A` — ANC, `T` — Прозрачность, `O` — Выкл)
  - **СКМ (средний клик)** по иконке трея — мгновенное циклическое переключение режимов
  - **ПКМ** — выбор режима, переключение между сохранёнными наушниками, эквалайзер и игровой режим
- **Полный контроль vivo TWS 5 Hi-Fi**:
  - Индикация заряда левого, правого наушника и кейса + положение в ушах
  - Звуковые профили **DeepX / Мастер звука (Hi-Fi)**
  - **Игровой режим** (низкая задержка) и автопауза при снятии
  - Настройка цикла долгого нажатия на ножку
  - Управление **Мультипоинтом** (подключение/отключение второго источника)
  - Поиск наушников звуковым сигналом

## Запуск

Из меню приложений KDE: **Kalm**, либо из терминала:

```bash
kalm               # Открыть графическое окно Kirigami
kalm --minimized   # Запустить свёрнутым в системный трей
```

## Команды терминала (CLI) и горячие клавиши

```bash
# Статус активных (или указанных через -d) наушников
kalm status
kalm status --json

# Переключение режимов шумоподавления
kalm anc --notify
kalm trans --notify
kalm off --notify
kalm toggle --notify
kalm toggle --modes anc,trans --notify

# Управление несколькими наушниками
kalm devices list
kalm devices scan
kalm devices add 1C:BA:B8:0F:5A:0F --alias "Основные"
kalm devices use "Основные"
kalm devices rename "Основные" "vivo Hi-Fi"
kalm devices remove "vivo Hi-Fi"

# Обращение к конкретной паре без смены активной
kalm -d "Основные" anc --notify

# Эквалайзер и игровой режим
kalm eq master     # standard | vocal | bass | treble | audiobook | master
kalm game on       # on | off
```
